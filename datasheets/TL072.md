## Description

The TL072 is a dual low-noise JFET-input operational amplifier from Texas Instruments, offering high input impedance, low noise (37 nV/sqrt(Hz) typical at 1 kHz), and low harmonic distortion (0.003% typical). It features a 3 MHz gain-bandwidth product, 13 V/us slew rate, and internal short-circuit protection, making it well suited for audio signal conditioning, active filtering, and buffer applications. In this project U4 provides two output buffer channels ("Buffer 1" and "Buffer 2"). The TL072C is the commercial temperature grade rated for 0 deg C to 70 deg C operation.

## Application Notes

- **JFET input characteristics:** The JFET input stage provides extremely high input impedance (approximately 10^12 ohm) and very low input bias current (65 pA typical), making the TL072 suitable for high-impedance source circuits and buffer stages where bipolar-input op-amps would introduce unacceptable loading or DC errors.
- **Power supply decoupling:** Place 100 nF ceramic bypass capacitors as close as physically possible to pins 4 (VCC-) and 8 (VCC+), with short traces to the ground plane. For audio or supply-noise-sensitive circuits, add bulk electrolytic capacitors (e.g. 10 uF) in parallel with the ceramics on each rail. This project supplies U4 from +/-12 V rails.
- **Dual-supply operation:** In this design the TL072 runs from the +12 V / -12 V rails, giving a wide, symmetric output swing (approximately +/-10 V into a 2 kohm load) well suited to buffering bipolar audio/CV signals.
- **Input common-mode range limits:** The input common-mode voltage range extends from VCC- + 4 V up to VCC+. With +/-12 V supplies, the valid input range is approximately -8 V to +12 V. Driving the input below the lower limit can cause output phase reversal, where the JFET input stage loses control and the output latches toward the opposite rail. Keep inputs within the specified range during all operating conditions including transients.
- **Stability with capacitive loads:** As with most op-amps, a large capacitive load directly on the output can cause peaking or oscillation. If driving a cable or capacitive node, add a small series resistor (typ 22-100 ohm) at the output, optionally inside the feedback loop, to preserve phase margin.
